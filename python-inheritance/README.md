# Python - Inheritance

This project focuses on Object-Oriented Programming (OOP) concepts in Python, specifically inheritance, method overriding, super calls, class type checks (`isinstance`, `issubclass`), and exception handling.

## Files & Tasks

| File | Description |
| --- | --- |
| `0-lookup.py` | Function returning available attributes and methods of an object. |
| `1-my_list.py` | Class `MyList` inheriting from `list` with a `print_sorted` method. |
| `tests/1-my_list.txt` | Doctest suite for `MyList`. |
| `2-is_same_class.py` | Function checking if an object is strictly an instance of a given class. |
| `3-is_kind_of_class.py` | Function checking if an object is an instance or subclass of a given class. |
| `4-inherits_from.py` | Function checking if an object is a subclass (excluding exact class) of a given class. |
| `5-base_geometry.py` | An empty class `BaseGeometry`. |
| `6-base_geometry.py` | Class `BaseGeometry` with unimplemented `area()` method. |
| `7-base_geometry.py` | Class `BaseGeometry` with `integer_validator()` implementation. |
| `tests/7-base_geometry.txt` | Doctest suite for `BaseGeometry`. |
| `8-rectangle.py` | Class `Rectangle` inheriting from `BaseGeometry`. |
| `9-rectangle.py` | Class `Rectangle` implementing `area()` and `__str__()`. |
| `10-square.py` | Class `Square` inheriting from `Rectangle`. |
| `11-square.py` | Class `Square` inheriting from `Rectangle` with customized `__str__()`. |
