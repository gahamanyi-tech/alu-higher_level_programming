# Python - Input/Output

This project covers file reading and writing, working with standard input/output, JSON serialization and deserialization, dynamic object loading, and algorithm practice in Python.

## Files & Tasks Description

| File | Description |
| --- | --- |
| `0-read_file.py` | Reads a UTF8 text file and prints it to `stdout`. |
| `1-write_file.py` | Writes a string to a UTF8 text file and returns written character count. |
| `2-append_write.py` | Appends a string at the end of a UTF8 text file and returns added character count. |
| `3-to_json_string.py` | Returns the JSON representation of an object (string). |
| `4-from_json_string.py` | Returns a Python object represented by a JSON string. |
| `5-save_to_json_file.py` | Writes an Object to a text file using JSON representation. |
| `6-load_from_json_file.py` | Creates an Object from a JSON file. |
| `7-add_item.py` | Script that adds all arguments to a Python list and saves them to `add_item.json`. |
| `8-class_to_json.py` | Returns dictionary description for JSON serialization of an object. |
| `9-student.py` | Class `Student` that defines a student and serializes to JSON. |
| `10-student.py` | Class `Student` supporting filtered JSON serialization with `attrs`. |
| `11-student.py` | Class `Student` supporting deserialization/reloading from dictionary. |
| `12-pascal_triangle.py` | Function returning Pascal's triangle of size `n` as list of integer lists. |
