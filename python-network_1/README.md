# Python - Network #1

This directory contains Python scripts for working with HTTP requests using Python's standard `urllib` package and the `requests` HTTP library.

## Tasks & Files

| File | Description |
| --- | --- |
| `0-hbtn_status.py` | Fetches intranet status using `urllib`. |
| `1-hbtn_header.py` | Fetches response header `X-Request-Id` using `urllib`. |
| `2-post_email.py` | Sends a POST request with an email parameter using `urllib`. |
| `3-error_code.py` | Sends an HTTP request and handles `urllib.error.HTTPError`. |
| `4-hbtn_status.py` | Fetches intranet status using `requests`. |
| `5-hbtn_header.py` | Fetches response header `X-Request-Id` using `requests`. |
| `6-post_email.py` | Sends a POST request with an email parameter using `requests`. |
| `7-error_code.py` | Sends an HTTP request and handles error codes >= 400 using `requests`. |
| `8-json_api.py` | Sends a POST request to a search API and parses JSON response. |
| `10-my_github.py` | Uses GitHub API with Basic Authentication to print user ID. |
