# Python - Almost a Circle

## Description
This project covers object-oriented programming (OOP) principles in Python, including inheritance, class and static methods, JSON serialization/deserialization, unit testing, and file I/O operations.

## Directory Structure
* models/: Contains Python classes (Base, Rectangle, Square)
* tests/: Contains unittest suites validating all classes and methods

## Usage & Testing
Run unit tests using the standard library discovery runner:
python3 -m unittest discover tests
