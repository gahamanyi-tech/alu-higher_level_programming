# Python - Test-Driven Development (TDD)

This directory contains Python projects focused on Test-Driven Development using standard Python `doctest` and `unittest` frameworks.

## Tasks & Files

| File | Description |
| --- | --- |
| `0-add_integer.py` | Function that adds two integers with type validation. |
| `tests/0-add_integer.txt` | Doctests for `0-add_integer.py`. |
| `2-matrix_divided.py` | Function that divides all elements of a matrix by a divisor. |
| `tests/2-matrix_divided.txt` | Doctests for `2-matrix_divided.py`. |
| `3-say_my_name.py` | Function that prints `My name is <first_name> <last_name>`. |
| `tests/3-say_my_name.txt` | Doctests for `3-say_my_name.py`. |
| `4-print_square.py` | Function that prints a square with the `#` character. |
| `tests/4-print_square.txt` | Doctests for `4-print_square.py`. |
| `5-text_indentation.py` | Function that formats text with newlines after specific characters. |
| `tests/5-text_indentation.txt` | Doctests for `5-text_indentation.py`. |
| `tests/6-max_integer_test.py` | Unittests for finding the max integer in a list. |
