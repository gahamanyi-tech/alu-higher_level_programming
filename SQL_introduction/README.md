# SQL - Introduction

This project introduces fundamental SQL commands for managing MySQL databases, tables, records, data aggregation, and basic conditional queries.

## Files & Descriptions

| File | Description |
| --- | --- |
| `0-list_databases.sql` | Lists all databases of the MySQL server. |
| `1-create_database_if_missing.sql` | Creates database `hbtn_0c_0` if missing. |
| `2-remove_database.sql` | Deletes database `hbtn_0c_0` if present. |
| `3-list_tables.sql` | Lists all tables of a target database. |
| `4-first_table.sql` | Creates table `first_table` with `id` and `name`. |
| `5-full_table.sql` | Prints the full creation schema of `first_table`. |
| `6-list_values.sql` | Lists all rows of `first_table`. |
| `7-insert_value.sql` | Inserts a new record into `first_table`. |
| `8-count_89.sql` | Displays record count where `id = 89`. |
| `9-full_creation.sql` | Creates `second_table` and inserts initial data set. |
| `10-top_score.sql` | Lists records sorted by `score` descending. |
| `11-best_score.sql` | Lists records with `score >= 10`. |
| `12-no_cheating.sql` | Updates `score` for 'Bob' to `10`. |
| `13-change_class.sql` | Deletes records with `score <= 5`. |
| `14-average.sql` | Calculates the score average as `average`. |
| `15-groups.sql` | Groups records by `score` and counts occurrences. |
| `16-no_link.sql` | Filters out empty names and orders by score. |
