# Python - Network #0

This repository contains bash scripts demonstrating networking fundamentals using `curl` to send HTTP requests, inspect headers, handle status codes, and transmit GET/POST data.

## Tasks & Files

| File | Description |
| --- | --- |
| `0-body_size.sh` | Sends a request to a URL and displays the size of the response body in bytes. |
| `1-body.sh` | Sends a GET request to a URL and displays the body of a 200 status code response. |
| `2-delete.sh` | Sends a DELETE request to the specified URL and displays the response body. |
| `3-methods.sh` | Takes in a URL and displays all HTTP methods accepted by the server. |
| `4-header.sh` | Sends a GET request with a header parameter `X-HolbertonSchool-User-Id: 98`. |
| `5-post_params.sh` | Sends a POST request with parameters `email=test@gmail.com` and `subject=I will always be here for PLD`. |
